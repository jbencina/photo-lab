# The photo viewer

A single tap or click on a thumbnail opens the photo viewer.

![The photo viewer with the details panel](/img/screenshots/lightbox.jpg)

| | Desktop | Phone |
|---|---|---|
| Next / previous | ← → (or the arrow buttons) | swipe left / right |
| Close | Esc | swipe down |
| Like | L, or double-click | double-tap |
| Details | I | the **Info** button |

## Details

The details panel (an info sheet on a phone) shows:

- the file name and date taken, with **Like**, **Find similar** and a link to the original file;
- an EXIF summary: camera, lens, focal length, aperture, shutter speed, ISO, dimensions and file size;
- the palette. Click a swatch to search the library for that color;
- the subjects, and a box to add a tag (see [Subjects and tags](tags.md));
- the full EXIF table, with common codes decoded. For example, ExposureProgram 3 is shown as
  "Aperture priority".

## Likes

Double-tap a photo (touch) or double-click it (desktop) to like or unlike it, with a heart burst. This
works in the grid and in the viewer. Likes are stored in the catalog's database, and the **Liked**
button in the dock shows only liked photos.
